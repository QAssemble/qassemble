# conda-forge recipes

Reference copies of the conda-forge recipes for QAssemble and its dependency
`pydlr` (not yet on conda-forge, so both are submitted together).

Submission: fork <https://github.com/conda-forge/staged-recipes>, copy
`recipe/meta.yaml` to `recipes/qassemble/meta.yaml` and
`recipe/pydlr/meta.yaml` to `recipes/pydlr/meta.yaml` in the fork, and open a
single pull request. After each release, update `version` and `sha256` here
and in the feedstock generated by conda-forge.
